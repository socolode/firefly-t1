# hardware · 硬件设计文件

存放萤火虫T1 的硬件相关设计与参考资料。

## 目录结构

```
hardware/
├── pcb/         # 电路板 Gerber 生产文件 + KiCad 原理图
├── schematic/   # 接线示意图（WS2812 / SK6812 / 灯环 / 矩阵等）
└── bom/         # 物料清单 BOM（元件型号、参数、采购建议）
```

## 说明

- PCB 文件为开源设计，欢迎自行打样或二次开发
- 接线示意图可作为入门搭建、硬件维修与扩展的参考
- BOM 含推荐型号与替代料，便于自制与维修
