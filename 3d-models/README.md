# 3d-models · 3D 打印模型

存放萤火虫T1 相关的 3D 打印文件。

## 目录结构

```
3d-models/
├── case/           # 主机外壳
├── time-ring/      # 时光环灯架 / 灯环
└── accessories/    # 配件：夹具、手柄、支架、灯罩等
```

## 文件格式

- `.stl`：通用切片格式，直接导入 Cura / PrusaSlicer 等软件使用
- `.step` / `.f3z`：源文件，便于二次修改定制

## 打印建议

- **材料**：PLA（外壳类）、PETG / ABS（受力配件）
- **层高**：0.2mm 即可获得良好外观与强度
- **支撑**：根据模型结构判断，悬空部位建议开启支撑
- **填充**：15%–20% 填充率足够日常使用
